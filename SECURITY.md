# Security Policy

## Reporting vulnerabilities

Do not publish sensitive vulnerabilities, credentials, invoices, catalogs or personal information in a public GitHub issue.

Use GitHub's private vulnerability reporting mechanism when enabled for the repository, or contact the repository maintainer privately.

## Sensitive data

Production invoices, catalogs, generated Excel files and logs may contain business-sensitive information. They must not be committed to Git.

The repository `.gitignore` intentionally excludes common document and output formats.
