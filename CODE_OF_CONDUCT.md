# Código de conducta

Este proyecto busca mantener un entorno profesional, respetuoso y colaborativo.

Se espera:
- comunicación respetuosa;
- revisión técnica basada en evidencia;
- documentación de decisiones relevantes;
- cero tolerancia a acoso, amenazas o discriminación;
- reporte responsable de problemas de seguridad.

Los mantenedores pueden moderar o rechazar contribuciones que incumplan estas reglas.
